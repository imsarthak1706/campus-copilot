# 🎓 Campus Copilot

Campus Copilot is an AI-powered student assistant that converts college notices into clear, actionable insights.

## 🚀 Features
- Upload **poster images**
- Upload **PDF notices**
- Paste notice text manually
- OCR-based text extraction
- AI-powered analysis
- Smart insights:
  - Priority
  - Urgency
  - Relevance
  - Category
- Personalized suggestions based on:
  - Department
  - Year
- Ready-to-send WhatsApp summary

## 🛠 Tech Stack
- Python
- Streamlit
- Gemini API
- OCR (Tesseract)
- PyPDF2

## 📦 How to Run

```bash
pip install -r requirements.txt
streamlit run ui.py
